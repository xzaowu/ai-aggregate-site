# Contributing

AI 聚合站 is licensed under Apache-2.0. Contributions are submitted under
the same license.

- Submit only code and assets for which you have the necessary rights.
- Do not submit secrets, credentials, private user data, customer assets, or
  media with unclear provenance.
- Preserve applicable third-party attribution and license notices.
- Keep changes scoped and document behavior changes.
- Run the existing validation commands when the environment permits.
- Provider-specific features must not bundle credentials.
- Record provenance for every contributed asset.

No CLA or DCO sign-off is required for OSS v0.1.
